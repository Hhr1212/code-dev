# 录屏工具（Recorder）

个人学习辅助工具：上课时在后台自动录制全屏，按小时分段，可以自动停止，方便课后回看、补抄笔记。纯本地运行，不上传任何数据。

## 功能特性

- 后台静默全屏录制，无弹窗、无控制台黑窗
- 可自定义数据保存位置（实际文件隐藏在子目录 cache 中）
- 按固定时长分段保存（默认每 60 分钟一个文件）
- 每天到设定时间自动停止（默认 17:45）
- 真 H.264 编码（PyAV / libx264，约 9MB/小时，OpenCV 作为回退）
- 录制文件以 .db 后缀伪装，实际格式为 MP4，改后缀即可直接播放
- 键盘输入记录：按「时间 + 事件 + 输入内容」整理，自动合并连续字符，可导出 TXT
- 管理密码保护：打开设置、播放、导出、删除均需验证密码
- 片段与输入记录支持批量导出、批量删除
- 自动清理 N 天前的片段与输入记录（默认 3 天），配置与密码永不清理
- 看门狗自恢复（计划任务），支持开机自启
- 兼容 Windows 10 / Windows 11

## 使用场景

- 课堂板书、课件来不及抄写时录屏，课后回看复习
- 仅限本人学习使用，请勿用于侵犯他人隐私的用途

## 技术栈

- Python 3
- PySide6：图形界面
- mss：屏幕画面抓取
- PyAV：H.264 编码（OpenCV 作为回退方案）
- pynput：键盘输入记录
- PyInstaller：打包为单文件、无控制台、管理员权限的 exe

## 目录结构

```
Recorder/
├── main.py        # 主程序：安装配置、录制、片段管理、输入记录、设置
├── 使用说明.txt    # 使用说明
├── 打开设置.bat    # 唤起设置界面
└── dist/          # 打包产物（不纳入 Git）
```

## 从源码构建

1. 安装依赖：

```
pip install PySide6 mss av pynput pyinstaller
```

2. 打包：

```
pyinstaller --onefile --noconsole --uac-admin --name sysmaint --collect-all mss --collect-all pynput --collect-all av main.py
```

3. 运行 dist 中的程序，首次启动按向导选择安装位置、数据保存位置，并设置管理密码。
4. 之后需要调整设置时，运行“打开设置.bat”并输入密码。

## 其他说明

- 录制文件与记录文件带有隐藏、系统属性；需在资源管理器中开启“显示隐藏文件”，并取消“隐藏受保护的操作系统文件”才能看到。
- 卸载需在设置界面输入密码，以停止防护并删除程序。
